## Implementation and limits

`scripts/tests/fixed-projection-catalog.php` builds the compiled29 P names,
seven N names and three hidden rows. It has no IO, options, clock reader, account,
SQL or caller-supplied policy. Only existing12-hex seed/24-hex ownership marker
and integer virtual clock samples are substituted. Strict canonical equality
follows bounded primitive validation, never unserialization of supplied data.
Case, trailing-space, legacy widget aliases, unknown/missing values, P/N overlap,
N physical-row models, altered hidden rows and a33rd options row refuse.

The exact PHP primitive strings retain eighteen30-byte empty widget values,
synthetic administrator roles, link_manager_enabled='0', empty permalink and six
canonical future cron jobs with version2/empty args/hash. Virtual T1800000000
gives1779 P-value bytes/979 cron bytes, not total memory or SQL evidence. Wall
seconds and monotonic milliseconds must agree within the original strict20s
root epoch; T derives from the original wall sample, never the latest check.

`scripts/tests/projection-shutdown-transcript.mjs` accepts only modeled FENCED,
normal core return, core shutdown return WITH cache close, one canonical candidate,
process exit0/no signal and both pipe EOFs under the same virtual deadline.
All six close/stdout-EOF/stderr-EOF orders are legal only after the candidate.
Any missing/repeated/out-of-order event, unknown/late activity, diagnostic, stderr,
output or deadline breach sticks. `violation()` latches BEFORE throwing a fixed
redacted error, so a caught exception cannot restore acceptance. Finish is one-shot.

Private candidate v1 is a fixed eight-position ASCII JSON array:
`[tag,1,root,case,profile,phase,counters,"modeled_only"]` plus one LF, <=4096
bytes. Root is24 lowercase hex; case is autoload/fallback; tag is
alynt.projection.candidate; phase is core_shutdown_returned. Canonical JSON
round-trip rejects whitespace, escapes, alternate numbers, extra fields/frames
and partial evidence. No raw SQL, credentials, paths or exception payload occurs.
Failure/extra frames refuse; no child failure-frame writer is installed.

Counters are twelve fixed-position nonnegative safe integers: attempted SQL,
completed data SQL, bulk hydration, P provenance, N requests, empty N results,
includes, writer intents, HTTP intents, diagnostics, core shutdown returns and
cache closes. Bounds: attempts<=32, completed<=attempts, bulk<=1, P=29,
N requests<=attempts/results=requests, includes1..1900, zero intents/diagnostics,
exactly one shutdown/cache close. These are MODEL domains, not a complete native
query/traversal bound. Requested/claimed empty N counts do not prove DB absence.

The shared profile is SHA256 of the literal model label
`alynt-fixed-projection.wp7.1.2.theme.v1`. It is NOT a complete source manifest,
installed-site identity, authority seal or certificate. No caller selects another
source/profile. Wrong-profile frames/catalogs refuse. Future composition still
needs independent exact source/config/include/callback/result qualification.

Only `synthetic_match` may be true. Native/authentication/absence/cleanup/storage/
wiring/execution claims are always false. There is no callable WordPress entry,
finalizer registration, writer-capable handle, cleanup executor, DB adapter,
process launcher, response suppression or availability owner in either helper.
Passing the model is not admission. The real eight-key worker stays unchanged.
