## Exact synthetic protocol and acceptance

Domain alynt.native-lifecycle-observation.selected.v1/version1; profiles
native_lifecycle_selected_commit_response_loss and native_lifecycle_no_fault.
Eight frames: parent boot1, worker root_request1, parent root2, worker
bind_writer2, parent bound_writer3, worker bind_barrier3, parent bound_barrier4,
worker final4. Common exact fields domain/v/kind/seq/attempt. BOOT/REQUEST/ROOT
and FINAL bind profile/source; ROOT establishes a distinct64-hex root token.
Grammar source is normative for field order/types, not an implemented channel.

Writer binding/ACK echo auth/capture/writer IDs, guard_index9, remaining_ns
canonical6..10-second duration. Barrier binding/ACK preserve all three IDs and
add a distinct barrier ID, guard_index21, positive root<=20s/read<=10s durations.
ACKs echo exact bindings/durations, not permission or new clocks. Parent measures
both ACKs<=1s from first bind byte, writer bind/ACK within first4s, strict original
root<20s from first ROOT byte; barrier durations start at first barrier bind byte.
No cut/bind/ACK/observation deadline reset; malformed/backward/overflow ticks fail.

FINAL requires registered_closed native result, barrier_verified=true,
candidate_only=false and six authority/closure/retry/storage/dispatch/execution
flags false. Exact10 pre+14 post guards and M,M,M,M,M,MF,M,MF,M,MF,M,S,S,F,S,F,
S,F,S,F,S,F,S,F;40 admission/10 barrier reads/one write/two metadata/two zero-DML
checks, writer erasure before read/barrier close before finish/original empty
slots. Qualification is separately sealed nine-field receipt with original13-
field result: uncertain(selected) OR committed(no-fault), released=true/current
acceptance=false, candidate-only/closed lifecycle and all authority flags false.
No old false/8+0, unavailable owner, false root, missing guard or missing close
can satisfy that positive oracle. Flags/fields are claims, not native evidence.

ASCII canonical JSON/LF,4096 bytes/frame,32768 bytes/transcript, depth8; duplicate
keys, escapes, unknown/extra/reordered fields, scalar/type/enum mismatch, partial
EOF, trailing bytes, replay and profile/source/root/role swaps refuse terminally.
One message per feed event, arbitrary fragmentation permitted. Source objects
with accessor fields refuse without invoking their getters.

Accounting model checks matching attempt/root separately from its opaque local
lifetime, four greeting IDs, capture close before writer bind, writer close before
beginRead/fresh barrier, barrier bind/credited COMMIT ACK before close/FINAL.
Canonical complete sequence1 OK is exactly11 framed bytes; upstream exact COMMIT
credit MUST precede arrival, never retroactively credited. Partial opposite
parser boundaries, tail/coalesced packets, prior response write attempts, wrong
credits or wrong role prevent selection permanently. Pre-cut ineligible data may
still be accounted transparently; after simulated cut no rearm/replay is possible.
Seven streams equal, selected stream equal-prefix+sole11-byte withheld suffix;
no global expected-loss waiver. No-fault profile balances all eight streams.

Original model caps:4096 frames/pair,2MiB/frame,8MiB pending,64MiB aggregate,
four semantic roles; root20s/read10s, selection first4s, writer close before10s,
root FINAL before expiry, cleanup28s separately. Virtual clocks/booleans are not
actual cancellation, server quiescence, resource settlement or native throughput.
The real8 accepted/4 live transport envelope is still a future relay obligation.
