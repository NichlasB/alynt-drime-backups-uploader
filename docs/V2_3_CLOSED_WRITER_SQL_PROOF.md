## Developer Harness and Review

`scripts/tests/closed-writer-local-proof.php` accepts only CLI invocation with the confirmed Plugin Tester root, verifies current LocalWP metadata/configuration and site URL, rejects multisite, persistent object cache and database/cache drop-ins, and uses `SHORTINIT` with cron disabled. It does not load/activate the uploader plugin. The existing release workflow excludes `scripts`; production loading and the existing runtime CAS allowlist are unchanged. CI adds syntax checks only, never LocalWP SQL execution.

The fixtures, native storage/CAS, transaction, processes, cases and race helpers are separate cohesive developer files. A native mysqli connection is used for both target writes and schema-6 CAS, avoiding wpdb reconnect/query filters and speculative option-cache invalidation inside a transaction. Reads use authoritative bytes; the prototype deliberately does not implement a production cache provider. Connection/read/row-lock/metadata-lock waits are bounded. Each native write is restricted to one exact randomly named `wp_alynt_writer_probe_<12hex>` table or its owned control table; this development fence is not a sandbox against arbitrary same-privilege code. Actual tables are used only for read-only structural cloning and baseline/audit reads. Tables must be absent before creation, are empty clones rather than copies of actual rows, and are removed only by the owning parent after child termination and row-count previews.

The synthetic target is fixed `probe_settings`, containing only a Boolean `auto_scan_enabled` and bounded integer `polled_at`. The only semantic delta is a server-computed Boolean toggle; private hashes bind exact bytes but are neither credentials nor authorization. Schema-3 closed fixtures migrate through the existing closed checkpoint to schema 6 without creating a grant. Begin is a separate committed CAS. The target/completion transaction locks the existing safety row first and the fixed target second, then validates the original immutable descriptor, epoch, site, binding, raw precondition and deadline. It conditionally writes target bytes and completes/removes only the exact pending token in the same transaction. Abandon uses identical lock order and authoritative before/after facts. A narrow timestamp fixture patches fresh bytes under the locks without copying stale semantic fields; a concurrent timestamp change conservatively invalidates the old whole-target precondition. It is not a complete production-writer inventory.

Native transaction calls contain no WordPress option hooks, HTTP, cron, queue or injected authorization callbacks; model guards are fixed fixture-only literal-true closures, not authenticated admission. Explicit interruption failpoints use a separate owned control connection solely to coordinate bounded test processes. No response is successful before `COMMIT`. Failed/unknown outcomes remain unresolved rather than asserting cancellation. Killing a process before commit must preserve the separately committed pending barrier; killing after commit but before its JSON acknowledgement must reconcile the original completion and raw target without replay. This is process/disconnect evidence, not simulation of server power loss or a transport failure during the COMMIT exchange.

The real cases cover missing state/default-off/denied grant and execution commands, nested transaction rejection without implicit caller commit, successful atomic target/completion, duplicate observation without replay, stale caches, actual SQL failures before target and after target/before terminal, missing target/corrupt/autoloaded state preservation, target preconditions and fresh narrow timestamp behavior, two competing finishers, finish-versus-abandon, paused writer after abandon/new begin, cooperating A-to-B-to-A epochs, both row-lock timeouts, expiry after a lock wait, interrupted before/after commit, bounded receipt history with terminal reserve, and unrelated fixture rows. Pure model tests remain separate evidence; the runtime receipt below records this SQL execution.
