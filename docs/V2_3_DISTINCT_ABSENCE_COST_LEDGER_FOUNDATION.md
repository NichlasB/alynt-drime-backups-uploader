## Fixed model contract and limits

The only evaluator accepts compiled v2 catalog, its six original identity/virtual-
clock arguments, autoload/fallback and a primitive list of six-slot events:
[tick,session,kind,name,outcome,rows]. No callback, SQL string, request, source
manifest, connection, arbitrary policy or writer-capable handle is accepted.
Every event belongs to this one virtual root epoch. Session labels are synthetic
core/verifier enums, NOT evidence about actual handles or authenticated provenance.

One illustrative driver prelude is connect/charset_api/charset_sql/mode_read/
mode_write/select_db. All six are required, ordered and individually counted as
three modeled APIs/three explicit SQL effects. This represents a nonempty SQL-mode
branch; it is not an exhaustive native driver profile or an instruction to force
that core branch. Verifier identity_grants markers can occur only before that
prelude, are separately counted, and cannot replace it or donate core-read credit.
Zero rows on API/driver/audit events is a non-data sentinel, NOT a claim about
actual driver result cardinality. Outcome'ok' is a supplied primitive model label,
not a measured server acknowledgement. Missing observability remains NO-GO.

Core bulk evidence must match the selected branch: one populated29-row marker,
or an empty autoload marker then populated fallback. Each reached absence has
paired API/read_attempt/miss markers for the SAME exact N name; only successful
zero rows earn one distinct credit. A repeated API/cache pair can reuse learned
absence without another SELECT. Populated P cache hits require compiled catalog
membership. Bulk cardinality is a symbolic fixture marker, not actual29 row/value
provenance; no cache/API replacement, SQL or physical alias check occurs here.

The model returns option attempts, successful data-result markers, conditional
B+D subtotal, distinct names, API/cache counts and separate driver/audit counts.
They do not sum into a whole-request cap. Positives allow reached-name subsets,
including zero; no extra reads are added to satisfy the separate v2 transcript's
eight-N fixture. That transcript is neither modified nor natively composed here.
All native/absence/driver-complete/resource/wiring/execution outputs remain false.

Finish is required after completed modeled work and refuses every later event.
It is not physical PHP shutdown/cache-close/engine/process/EOF/cleanup proof.
No partial/error/reconnect/replay/unknown trace is rescued by a positive count.

all production/worker timeouts, budgets, grants and source contracts are unchanged.
